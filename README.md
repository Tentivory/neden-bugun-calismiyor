# Neden Bugün Çalışmıyor?

## Bu Repo Nedir?

Bu, insanlık tarihinin en önemli bilimsel başarısıdır. Kodunuz çalışmadığında "neden?" diye sorduğunuzda, artık rastgele ve tamamen mantıksız ama **ciddi** bir açıklama alabilirsiniz.

Bu araç, NASA, CERN ve köşedeki bakkal tarafından onaylanmıştır (onaylamamışlardır ama olsun).

## Nasıl Kullanılır?

```bash
python neden_bugun.py "SyntaxError: unexpected EOF"
```

Çıktı olarak size tamamen bilimsel bir sebep verecektir. %100 doğrudur. Şüphe etmeyin.

## Özellikler

- 15 farklı absürt sebep
- Her çalıştırmada rastgele seçim
- Hiçbir şeyi çözmez, sadece açıklar
- Kahve içmezseniz daha da kötüleşir

## Uyarı

Bu repo ciddiye alınmamalıdır. Ama alınmalıdır. Çünkü eğer almazsanız, kodunuz yine çalışmaz.
